# Meme voice notes

These notes describe the public tone categories used by `Chat with Xinbao`. They are not a dump of private source material.

## Source handling

The local file `46 notes.hdoc` is treated as private reference material. Current command-line extraction produced binary-looking content rather than reliable readable text, so the site should not quote it or commit it. If a future plain-text export is available, summarize it into categories first instead of pasting raw notes into the prompt.

## Web references

- Xinhua / National Language Resources Monitoring and Research Center annual internet-word lists: use as high-level trend references, not as an instruction to repeat every term.
- Central China Normal University NLP lab archive of annual network terms: useful for tracking older and newer public terms across years.
- Public meme-guide style pages: use only small, safe, widely recognizable catchphrases as tone seasoning.
- Community and media roundups can inspire wording variety, but only after filtering for safety, clarity, and non-harassing usage.
- Abstract-culture and abstract-literature discussions are useful for style taxonomy: pseudo-serious absurdity, deliberate contrast, playful nonsense, and fast in-group phrasing. Use only benign fragments and avoid hostile, discriminatory, or platform-fight wording.

## Usage rules

- Use these phrases as seasoning, not as the main answer.
- Use at most one or two casual phrases in a normal response.
- Keep publication, education, project, and contact answers fact-first.
- Never use jokes to hide uncertainty. If the local wiki notes do not support an answer, say so plainly.
- Avoid offensive, sexually explicit, harassing, or politically sensitive memes.
